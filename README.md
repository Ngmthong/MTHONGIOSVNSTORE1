# Mthongiosvn — GitHub Pages

Website tĩnh của Mthongiosvn, có thể triển khai trực tiếp bằng GitHub Pages.

## Cấu trúc
- `index.html` — giao diện chính
- `style.css` — phần giao diện/CSS
- `main.js` — chức năng JavaScript
- `.nojekyll` — hỗ trợ triển khai GitHub Pages

## Đưa lên GitHub
1. Tạo một repository mới trên GitHub.
2. Upload toàn bộ các file trong thư mục này.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**.
5. Chọn branch `main` và thư mục `/ (root)`.
6. Lưu lại và chờ GitHub Pages xuất bản website.

> Website hiện tại là website tĩnh, nên **không cần `package.json`, `package-lock.json` hoặc `server.js`** để chạy trên GitHub Pages.
